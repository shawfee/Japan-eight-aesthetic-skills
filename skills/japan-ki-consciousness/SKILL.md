# 气 (Breath/Aura) — 一体化氛围的全身感知

## R — 原文 (Reading)

> 气是人或物与宇宙之间的一体感。
>
> — 黑川雅之《日本的八个审美意识》气章(印刷 p42–59)

> 日本人所理解的人或物，并不仅仅是指人或物体本身，而是"包含了周围空气的人或物"。人会从身体内部向外释放出一种类似于具有延展性的区域空间的气场。气场也属于这个人身体的一部分。
>
> — 黑川雅之《日本的八个审美意识》气·气与气场(印刷 p42–59)

> 即便不像洞穴那样可以遮风挡雨，也足以让疲惫的旅行者产生安心的感觉……这棵树、那块岩石，无疑就是可以让人心情平静、安心依靠的场所。所以我认为，这就是建筑的原点。
>
> — 黑川雅之《日本的八个审美意识》气·柱子是气场建筑(印刷 p49)

---

## I — 方法论骨架 (Interpretation)

气不是某个孤立的实体，而是一种"关系状态"——人/物与周围空气、与宇宙连成一体的感觉。你感知一个对象时，不只在看它的物理边界，还在用整个身体去读它向外弥散的氛围能量（气场）。

气场不是包围对象的装饰，而是这个身体向周围扩张、且属于它自己的领地空间。这套意识最反直觉的一点在于它靠"反衬"成立：它不是通过区分"你我""内外"来工作，而是恰恰否定这种分隔——当自他的边界消融，一体感才浮现。

所以它要求从"分析实体"转向"感知场"，从"大脑理性"转向"全身感性"（p48）。气要能被调动，需要素直/率真的状态（怯懦则封闭）；而气场一旦被高密度持续入侵，感知会主动麻木以自保（ce16）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 洞穴 vs 柱子——建筑的两种起源 (c32)
- **问题**: 西方建筑（洞穴、实体包围）与日本建筑的差异究竟在哪？
- **方法论的使用**: 把建筑理解为"由气场生成的空间"而非实体遮蔽；柱子向外散发气场，形成的是"心灵的空间"。
- **结论**: 日本建筑的起点是柱子（气场、象征性心灵支撑），西方是洞穴（实体）。
- **结果**: 作者确立"日本建筑即由气生成的间"。

### 案例 2: 多根柱子形成的母性包围感 (c34)
- **问题**: 单根柱子只是父性象征，如何形成整体的环境感？
- **方法论的使用**: 多根柱子以近距离排列，各自气场叠加、朦胧合成整体，"似墙却非墙"，由气的叠加生成"间"。
- **结论**: 日本空间是气叠加后的连续整体。
- **结果**: 庭院不像西方内外对立，而是内外连续贯通。

### 案例 3: 气场打造的村落 (c36)
- **问题**: 村落如何自组织，而不靠自上而下的整体规划？
- **方法论的使用**: 各家在彼此在意、体谅的气场感知下，顾及不遮挡他人光照/景色、保持适度间距，形成并列。
- **结论**: 气是取得整体和谐的要素，村落由气场感知下的并列关系构成。
- **结果**: 不同于西方"从整体规划到个体"的城市生成方式。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计空间/产品时，用户觉得"冷/没有氛围/不像一个整体"，却说不清哪里不对。
2. 团队或人际场景需要恢复"一体感/默契/在场感"，而不是再加规则。
3. 评估一个环境/界面给人"安心/舒展"还是"压抑/被侵入"的具身体感时。
4. 做品牌/符号/空间锚点，想用一个最小象征物提供心理依靠（一根柱子也是建筑）。
5. 创作或引导孩子学习，想调动内在动力而非靠命令施压。

### 语言信号 (用户的话里出现这些就应激活)

- "感觉没有氛围 / lacks atmosphere / 没有一体感 / no sense of unity"
- "这里好冷、好压抑 / feels cold / suffocating / 气场不对"
- "想让人安心靠一下 / need an anchor / 心灵支撑 / 安心感"
- "大家不在一个频道 / not in sync / 气场不合 / 在场感缺失"
- "怎么调动他的积极性 / how to motivate without pressure / 他没那个气"

### 与相邻 skill 的区分

- 与 `japan-ma-interval`(间) 的区别: 气是能量/氛围本身；间是由气构成的媒介性空隙（停顿、间距、余白）。先有气的延展，才有所谓"间"。不要见空就喊气、见气就喊间——气是"在场"，间是"在场之间的停顿"。
- 与 `japan-micro-consciousness`(微) 的区别: 气是全身对氛围的感知状态；微是从细节/个体看见整体的视点。微是"看什么"（局部即全体），气是"怎么感觉"（一体化氛围）。一个偏认知视角，一个偏身体感知。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **定位气场边界**
   - 完成标准: 能用一句话描述该空间/人/物向外延展的"领地"范围与基调（如"这个工位区气场是封闭、防御性的"），并标出他人靠近到什么距离会感到被侵入或被接纳。

2. **检测压制与麻木**
   - 完成标准: 标出至少一处"气场被持续入侵"或"气被封闭"的迹象。
   - 判停条件: 若发现 ce16（密度过高致感知麻木）或 ce17（靠施压/重复命令驱动）模式，跳到步骤 4 先解除压制，不要直接营造气场。

3. **以最小象征物重建一体感**
   - 完成标准: 给出一个具体的最小锚点方案（一根柱子、一个符号、一处留白），并说明它如何向外生成气场空间，而非堆砌实体覆盖。

4. **解除压制 / 恢复素直**（步骤 2 的判停目标）
   - 完成标准: 列出可执行的"减量/撤压"动作（降低密度、撤除命令、以率真状态替代催促），使气场感知得以恢复。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill (反场景)

- 纯物理量/工程参数能解决的问题（承重、带宽、时序）——不需要气场视角。
- 需要精确、可证伪的量化评估时（气无法被测量，见 ce35）。
- 用户只是要客观事实/数据查询，而非氛围/关系/一体感判断。
- 跨文化或政治优越论语境——不要借气做民族本质化论证（见 ce37/ce38/ce44）。

### 作者在书中警告的失败模式

- **ce16 高密度环境系统性扼杀气场感知**
  - `failure_mode`: 在爆满车厢、开放式工位、群聊轰炸等无缓冲环境里要求人保持敏锐气场感知，结果是感知力主动关闭以求自保——先是不打招呼，后把人当障碍物；归因于"个人素质下降"会彻底走错方向。
  - `warning_signs`: 同楼邻居/同组同事擦肩而过不打招呼；把冷漠解释为素质问题而非密度问题。

- **ce17 靠施压和重复命令去驱动别人的"气"**
  - `failure_mode`: 用命令、催促、责骂、重复提醒推动他人，每重复一次加固对抗，对方把气更深地封闭，形成"越催越不动"的稳态，施压者却认定"是他不上心"。
  - `warning_signs`: 同一件事已提醒三次以上且措辞递增；对方出现防卫/回避；转机只在压力被撤除的瞬间出现。

- **ce35 把"气"当可测物理量或万能解释**
  - `failure_mode`: (a) 把气当光/电磁波/能量等物理实体，与科学冲突，论证失可靠；(b) 把气当万能解释，"气场不对"成为不可反驳的否决理由，团队无法对齐，判断退化为权威直觉裁定。
  - `warning_signs`: 凡说不清的都归因于气；以"气场不对"否决方案却不给可检验理由。

### 系统级边界（来自阶段 0 批判）

- **反通用设计超老龄化失效 (ce46)**: 本书反对"谁都能用"的通用设计，但这是作者最强盲点——书内和服/包袱方巾恰恰"一种形状适配所有身体"。在超老龄化、无障碍、包容性场景，不能因"尊重个体气场"拒绝通用性/无障碍需求。
- **不当完备清单 (ce36)**: 八意识是作者自陈的"试论/剖面图"，数目并不稳定（破章一度只列七个）。不要把气当成某检查表的一项，缺项即判不合格。
- **不当日本独有 (ce37)**: "气"字来自中国，书中自陈与东方传统同构。不要以"日本独有"排他，或把东亚共有经验误判为民族本质。
- **不性别本质化 (ce38)**: 书中以洞穴=女性、柱子=男性等身体隐喻做审美判断。不要把"阴性/无自我主张/包容"规范为女性属性，也不要用性别隐喻替代对结构的具体分析。
- **不移植数字对象 (ce40)**: 气的动力来自身体与可风化素材的真实接触；数字对象无素材、不可触、不风化，不能直接套"素/假"结论，别把木纹贴图当气场。
- **不归罪西方 (ce44)**: 不要用"你的批评是被西方价值观毒害"来终止讨论；质疑"气在此处不适用"应被认真回应，而非读成文化不忠。

### 本意识专属边界

- **气 ≠ 可测物理量**: 作者明确"姑且不论它的物理属性"，气是存在于人内心的一种力量、是体感，不是光或电磁波。不要用科学仪器去"测气"。
- **气场是实体化领地，非玄学**: 气场是个体向外延展、属于自身的空间（可被侵入、可麻木），是具身边界，不是神秘 aura。谈气场时落到"距离/密度/是否被侵入"的具身尺度，而非神秘化。
- **气 ≠ 万能解释**（见 ce35）。
