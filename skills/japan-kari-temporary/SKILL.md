# 假 (Kari / Temporary) — 暂借、顺势、可弃的融通空间

## R — 原文 (Reading)

> "不去抗拒,顺势而为的美。这就是'假'的含义。'假'也有'借'的意思。"
>
> — 黑川雅之,《日本的八个审美意识》假·对大自然的绝对信赖(印刷 p110)

> "肉身不过是灵魂临时借居的躯壳而已。"
>
> — 黑川雅之,《日本的八个审美意识》假·对大自然的绝对信赖(印刷 p110-112)

> "生也罢,死也罢,都是'假'(借)道自然的美丽流程。"
>
> — 黑川雅之,《日本的八个审美意识》假·对大自然的绝对信赖(印刷 p110-112)

---

## I — 方法论骨架 (Interpretation)

"假"读仮(kari),核心是**借来、暂定、终将归还**,绝不是"虚伪/虚假"(偽)。常识极易把"假"误读为不真,作者义是:万物(生命、房屋、当下方案)都是向自然借来的临时形态,因此可以低依恋地迭代、可弃、可转化,并顺势而为、不抗拒无常。

它的实践骨架有三层:(1) **暂定**——把方案当可弃原型而非永久承诺;(2) **融通无碍**——空间/功能不必固定,用可移动边界让一物多用、内外连续;(3) **转化**——对熟知概念做角色逆转(建筑↔家具↔环境等价)获得新见。

**回看「反衬」(g17)**:八个意识多"通过相反概念实现",而假的反衬是**消解自我与执念**——"在完全信任宇宙规律的前提下顺应时势,连自我都消失无踪了"。假不靠强硬意志推进,而是借、是忍、是暂歇;它看似消极退让,实则因放下"必须如此"的执念而腾出融通余地,这正是最危险也最有生命力的反衬。

**★ 必须显式区分**:仮 = 借来/暂定(可弃、顺势、尽责维护) ≠ 偽 = 虚假/虚伪。把"假"理解成"不必认真/可以糊弄",是把它滑向了偽,已偏离作者本义。

## A1 — 书中的应用 (Past Application)

### 案例 1: 移门打通——融通无碍的空间(c79)
- **问题**: 房间功能被固定墙体重重分隔,空间僵化、用途单一。
- **方法论的使用**: 用可拆的隔扇/移门,让相连房间瞬时打通;客厅、中厅、饭厅、茶室都只是"临时的用途",不是功能明确的具体房间,达成融通无碍、内外无别。
- **结论**: 所有用途都是暂时的、"假"的,这就是日本房屋的空间概念。
- **结果**: 农家用挪开移门即得可办红白喜事的大空间;作者判定日本房屋是连续的"假"空间,与西方先墙后窗相反。

### 案例 2: 日本房屋=家具(c81)
- **问题**: 用西式"建筑"框架理解日式房屋,硬塞西式家具显得怪异。
- **方法论的使用**: 把房屋视为"一张巨大的床/一件家具"——人"睡"在其中而非"住"进各房间;建筑在拓扑上等价于可放入的器物。
- **结论**: 日本的房屋本身就是家具,在家具里再放家具是不可想象的。
- **结果**: 西式家具搬入显怪异;作者点出建筑↔家具在拓扑结构上等价(与 c83"工作室·昂达"、c84 西方洞穴转化互为印证)。

### 案例 3: 汽车转化为摩托车(c82)
- **问题**: 想说清"环境"与"物体"到底什么关系。
- **方法论的使用**: 对汽车做"切开车顶翻转"的拓扑逆转推想——封闭车内逐渐裸露,司机坐进"曾经是车的物体"中。
- **结论**: 人在车里车是环境,人在车外车是物体;切除翻转后即成摩托车。
- **结果**: 作者以"气场"解释内外逆转,演示万物暂定、可转化;摩托车、家具与日本房屋"并无本质区别"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 做 MVP/原型,想避免一次性投入却又纠结"不够完美不能发"——需要低依恋的暂定心态。
2. 设计灵活空间/系统(小户型、模块化办公、一物多用),希望同一载体承担多用途、边界可流动。
3. 遇到卡点,越想控制越做不出来,想"顺其自然、把结果交给偶然"而非硬推。
4. 想把某项方案/合作明确为"临时、可弃、借来",需要语言框架向他人说明"这不是最终承诺"。
5. 做概念重构/跨界类比,想借"角色逆转"把熟悉事物翻成新形态。

### 语言信号(用户的话里出现这些就应激活)

- "先做个临时版 / 不必永久 / 暂定就好 / 借来用 / 顺其自然 / 先迭代再说"
- "这个不是最终方案 / 先跑起来再调 / 低成本的试错"
- "prototype first / temporary / borrowed / makeshift / go-with-flow / not final / throwaway"

### 与相邻 skill 的区分

- 与 **素(Plain)** 的区别: 素管"本真、素材优先、人工无痕、回到原型";假管"暂定、可弃、借来、顺势转换"。素回答"是什么材料/本相",假回答"能借多久、可不可弃、怎么变通"。同一物(如 c81 房屋)可同时被两意识解释,但调用意图不同。
- 与 **破(Break)** 的区别: 假是"顺势暂借、融通无碍",是消极退让式的容纳;破是"成熟后主动打破以生成新范式",且须置于守破离(先熟而后破)。假不打破,只是让边界流动;破要砸开旧形。
- 与 **间(Ma)** 的关系(构成,非对立): 假的空间靠"间"的流动空隙实现融通无碍,二者常同现(如移门打通即造间)。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **标定"暂定性"与归还路径**
   - 完成标准: 列出当前对象/方案中哪些可视为借来、可弃、低依恋,并写明"何时归还/替换/弃用"的触发条件。若对象本就需永久承诺,则跳到步骤 3 边界检查。

2. **设计融通/可转化的临时结构**
   - 完成标准: 给出至少一种"可移动边界 / 可逆转角色 / 一物多用"的具体方式,使同一载体能临时承担多用途(参照 A1 的移门、家具、拓扑逆转)。
   - 判停条件: 若涉及**安全、契约、不可逆、他人权益**,**立即跳到步骤 3**,不得用"暂定"弱化处理。

3. **设置维护责任与判停机制**
   - 完成标准: 明确"暂定≠不维护"——写明维护责任(只补损坏处、保留修复痕迹,见 ce27)与弃用/转化条件;确认未滑向"以假为借口放弃照料"或"审美压过安全"(见 ce48)。

## B — 边界 (Boundary) ★

### (a) 不要在以下情况使用此 skill(反场景)

- **契约/法律承诺**: 合同、协议、责任归属不能"暂定了事"——签署即需确定性。
- **安全/可靠/不可逆决策**: 结构安全、医疗、数据不可逆删除、他人生命健康,不能以"顺应自然/暂定"弱化处理。
- **需要长期稳定维护的系统**: 基础设施、生产环境不应以"融通无碍"为由省略冗余与责任人。

### (b) 书中警告的失败模式(来自反例 extractor)

- **ce27 — 把"假(暂借)"当成放弃维护的借口**
  - `failure_mode`: 以"一切都是暂时的、借来的"为名不修、不洗、不管;把破损当侘寂、脏当质感、凑合当顺势。结果只剩腐坏而非风化,且易滑向"偽"——用美学词汇为敷衍开脱。
  - `warning_signs`: 有裂口却无任何修补动作;分不清"该保留的痕迹"与"该处理的损坏"且无可依据标准;用"侘寂/暂定/迭代中"解释长期未处理项;使用者感到被怠慢而非被照料。

- **ce48 — "不需要任何人为干涉"审美压过安全性**
  - `failure_mode`: 把"绝对信赖自然、顺势而为、不做人为干涉"从审美主张扩展为工程/安全决策原则;明知材料/流程有系统性风险(易燃、易腐、不可逆、无冗余)仍以"顺应自然"维持原状,把可预防损失记为宿命(书中江户屡次大火而不改即实证)。
  - `warning_signs`: 已发生同类事故方案仍未变更;用"顺应自然/保持本色"回应安全/可靠性质疑;讨论中无"失效模式"与"恢复成本"两栏;把"不干涉"当立场而非有代价的选项。

### (c) 系统级边界(来自阶段 0 批判 / M 共享桶)

- **不用于超老龄化/无障碍/包容性场景失效(ce46)**: 作者"反通用设计"是强盲点;当涉及无障碍、适老、谁都能用时,本 skill 的"顺其自然"不得压过包容性诉求。
- **不当完备清单(ce36)**: 八意识不是设计方法论的全集,假只解"暂定/融通",不覆盖其它维度。
- **不当"日本独有"(ce37)**: 暂借/低依恋迭代是人类通用实践,勿神化为日本专属。
- **不性别本质化(ce38)**: 勿把"顺势/不干涉"归因某性别气质。
- **不移植数字对象(ce40)**: 前现代的"风化更美/暂定"不能直接套数字系统的版本/持久化/数据完整性。
- **不归罪西方(ce44)**: 融通无碍不是"优于西方封闭分隔"的论据,只是不同空间观。

### (d) ★ 本意识专属边界(最关键)

- **仮(借暂) ≠ 偽(虚假/虚伪)**: 假是"暂定、可弃、顺势、向自然借形终将归还";绝非"不真、敷衍、虚伪"。任何把"假"当"不必认真"的解读都已滑向偽,偏离作者本义。
- **假 ≠ 放弃维护(ce27)**: 暂定仍须尽责——只补损坏处、保留修复痕迹,痕迹之所以美是因它是照料的证据;去掉照料一半,假就只剩衰败。
- **审美不压安全(ce48)**: "顺应自然/暂定"的评价函数不含安全性与可恢复性项;一旦用于同时决定安全的场景,安全会被静默归零。凡涉安全/契约/不可逆,立即退出本 skill(见 E 步骤 2 判停)。
