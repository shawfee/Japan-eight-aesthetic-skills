# 盲测目录 — 8 个 skill 的 name + description + 关键触发语

> 供阶段 4 压力测试的独立 sub-agent 做"该激活哪一个"的选择题。请勿当作答案，只作候选清单。

## 1. japan-micro-consciousness（微）
- description: 面对复杂系统无从下手、或手握宏大框架却落不到实处时激活：需从一个具体局部/个体/当下瞬间入手，让整体从中浮现，而非先画全景再填空。关键 trigger: "从细节入手 / see the whole in details"、"局部视角"、"一期一会 / ichi-go ichi-e"、"从内向外 / inside-out"、"个体即整体"。不适用于纯信息查询、需大盘指标汇总、问题实为缺全局对齐、只想"抠细节/精细化"而不问细节承载什么整体（那是碎片化打磨）。

## 2. japan-parallel-consciousness（并）
- description: 安排"多个对等主体如何共存而不设中心"时使用：扁平化/去中心化、几个方案能否都留着不二选一、版面非要主焦点吗、多种价值观怎么并存、没有 leader 的社区怎么自组织。不适用于需统一指挥的危机攻坚、必须收敛唯一结论与责任人的决策、要求事实一致性的合规/安全/事故复盘、以及需要把单一体系掌握到可实践程度时（并列会退化成"都可以"式无主张）。

## 3. japan-ki-consciousness（气）
- description: 判断或营造空间/人际的"氛围、一体感、气场空间 aura/atmosphere"时使用：这里好冷/没有氛围、大家不在一个频道/没有一体感、怎么调动积极性（不靠施压）、想让人安心靠一下（一根柱子也是建筑）。不适用于纯工程/量化参数问题、需可证伪的客观评估、纯事实查询，以及借"气"做民族本质化或万能解释（气≠可测物理量）。

## 4. japan-ma-interval（间）
- description: 设计留白 negative-space、停顿 pacing、间距 interval/spacing、余白、呼吸感、节奏间隔、暧昧过渡、无名衔接带时调用：用"空"而非"满"承载意义、关系与余韵。不适用于纯信息查询、纯技术实现、需要明确传达或补齐信息的场景（此时用"秘"或直述）。trigger: 留白/停顿/间距/呼吸感/余韵/间隔/暧昧/节奏/pacing/negative-space/interval/white-space/ma。

## 5. japan-secret-consciousness（秘）
- description: 在沟通、内容、教学、设计中追求"让对方自己想通/想进来"而非"说尽说清楚"时调用：产品文档/文案/演讲/界面用留白与隐去驱动读者想象与共创，不把多元解读当失败。当用户说"写详细点/说清楚/确保 100% 理解"，或场景涉及法律、安全、医疗等须准确传达的场域时，不调用。trigger: 不说尽 / 留白驱动想象 / 余白 / 余情 / withhold-to-invite-imagination / leave-room-for-the-reader。

## 6. japan-plain-consciousness（素）
- description: 任务需要做减法、回到未加工本真、让素材而非造型说话、用形式限制激发创意、规避过度设计与自我表现时。典型诉求: "太花哨了怎么减""素材优先还是造型优先""用最少约束做原型/MVP""回到本质"。不适用于纯信息查询、公共/无障碍/包容性场景（超老龄化下"素"失效）、安全或功能不能被"素"牺牲、数字对象无真实可风化素材时勿生搬"风化更美"、把"素"当低成本/匮乏借口。

## 7. japan-kari-temporary（假）
- description: 需要低依恋迭代、暂定原型、把方案视为可弃/可借的临时空间，或主张"顺势而为、不抗拒"时使用（temporary / borrowed-form / makeshift / 融通无碍 / 顺其自然）。不适用于契约/安全/不可逆决策等需要确定承诺的场景，也不适用把"假"当放弃维护或审美压过安全的借口。trigger: "先做个临时版""不必永久""暂定就好""借来用""顺其自然"；"prototype first / temporary / borrowed / go-with-flow / not final"。

## 8. japan-break-innovation（破）
- description: 已精通某套方法/规范、却想突破现状、引入突变或颠覆式创新（打破常规/守破离/break-the-rules/after-mastery/shu-ha-ri）时调用。不适用于尚未掌握既有规范就谈创新（先守后破，未守不破）、安全/合规/不可逆领域、把"破"当损坏（破≠损坏）或当可复制激励技术。trigger: "流程僵化想打破""学无可学想创新""用突变/偶然驱动""打破书院造式秩序"。
