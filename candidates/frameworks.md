# 可迁移思维模型 / 决策框架 / 推理方法 — 候选清单

> 来源:《日本的八个审美意识》(黑川雅之),全书 OCR (`source_ocr.txt`)。
> 提取人:framework-extractor(阶段 1)。本清单**不做筛选**,宁多勿漏,交由阶段 1.5 去重。
> 说明:8 个意识(微/并/气/间/秘/素/假/破)各自本身即是一个"怎么想"的结构,均作为 framework 收录;其余为书中可迁移的衍生思考结构。

- id: f01
  title: 微 — 细节中体现整体
  type: framework
  source_chapter: 微·细节中体现整体 (印刷页 1、13–15)
  source_quote: |
    "现在"中有时间的一切。"这里"有空间的一切。"个体"内有"人"的一切。
    这个理念深藏于日本思想的根源之中……日本人并不习惯这种思维(整体包含细节),
    他们认为个体中有社会,细节中有整体,并会尝试从细微之处来看整体。
  summary: |
    面对复杂系统时,不从"俯瞰全局"入手,而从"极小个体"入手——相信整体已蕴含于每个局部。
    方法:先抓一个具体的"点"(此时、此地、此人),把它看透,整体自现。
    适用:产品细部取舍、文本细节、个体案例研究、从个案推整体。
    反向提醒:这是与"先框架后细节"相反的推理路径(自底向上而非自顶向下)。
  tags: [mental-model, bottom-up, micro, 局部即整体]

- id: f02
  title: 一期一会 — 珍惜不可复现的当下
  type: framework
  source_chapter: 微·一期一会 (印刷页 1、13–14)
  source_quote: |
    "一期一会"阐述的是:现在能够与这个人交流的瞬间不会再来,所以要加倍珍惜当下的时间。
    眼前的这一瞬包含了过去和未来,这就是"微"的精髓。
  summary: |
    把每一次相遇/事件当作"唯一、不可重复"的切片来对待。推理前提:此刻=过去+未来的压缩。
    方法:做决策或待人接物时,先假定"此瞬间不再来",据此决定投入与珍视程度。
    适用:人际、会谈、创作节点、任何"一次性情境"的价值评估。
  tags: [mental-model, presence, 一期一会, time]

- id: f03
  title: 从内向外放射状视角 — 局部即宇宙缩影
  type: framework
  source_chapter: 微·描绘城市从室内开始 (印刷页 15、21–29)
  source_quote: |
    茶室中隐含了几个日本审美意识的要素……视线从室内的榻榻米延伸到走廊,再从走廊延伸到庭院,
    然后到围墙,甚至一直到远处的群山。房屋只是自然乃至宇宙中很小的一部分,但这个空间却能将世界纳入自己的视线。
  summary: |
    理解世界不从外部上帝视角,而从"我所在的这个点"向外放射。方法:以"这里"为原点,
    逐层延伸(室内→走廊→庭院→远山→宇宙),由点及面地感知整体。
    适用:空间/信息架构、叙事视角、任何需要先锚定一个具体观察点再外推的场景。
  tags: [mental-model, perspective, 放射状, 借景]

- id: f04
  title: 内与外的同质性 — 连续而非对立
  type: framework
  source_chapter: 微·内与外的同质性 (印刷页 21–22)
  source_quote: |
    日本人始终认为内与外是一体的……这种外部与内部既互相尊敬又十分亲密的关系,

  summary: |

  tags: [mental-model, continuity, non-dual, 内外一体]

- id: f05
  title: 村落式城市 — 微观决定论的涌现
  type: framework
  source_chapter: 微·日本的城市是村落 (印刷页 22–26)
  source_quote: |
    日本是先有微观概念上的房屋。房屋集结到了一起之后,形成了村落型的城市。
    西方是城市概念在先,建筑属于其中的一个组成部分,这两种发展模式产生的是截然相反的结果。
  summary: |
    建构复杂系统(城市/组织/产品生态)时,优先定义"最小单元"并让其自然聚合,
    而非先规划"总体"再分割。方法:先有个体房屋+适度间距→自然涌现村落;
    反对"宏观城市支配论"。适用:社区设计、自下而上的平台/生态构建。
  tags: [mental-model, emergence, bottom-up, 微观决定论]

- id: f06
  title: 并 — 并列无中心、对等的协调
  type: framework
  source_chapter: 并·日本的民主主义 (印刷页 20、32–34)
  source_quote: |
    "并"这种审美意识的概念是,单纯地把并列的、没有上下级关系的多个局部聚合起来而产生的和谐关系。

  summary: |
    处理多主体关系时,默认"平等并列、无中心、无主从"。方法:让每个独立个体自发协调,

  tags: [mental-model, parallel, decentralize, 无中心]

  type: framework
  source_chapter: 并·万神 (印刷页 34–37)

- id: f08
  title: 绝对与相对 — 羞耻意识 vs 原罪意识
  type: framework
  source_chapter: 并·绝对与相对 (印刷页 38–39)
  source_quote: |
    西方的价值标准……表现为一种"没脸见人了""在别人面前怎么好意思"之类的"羞耻意识",
    绝对不是西方的"原罪意识"。日本人重要的是在意他人感受……完全是以人际关系为标准为规范着一切。
  summary: |
    决策/行为判准有二源:外部绝对标准(上帝/法则/正确)vs 内部相对标准(他人感受/羞耻/和谐)。
    方法:当问题关乎人际协调时,用"对他人的影响(羞耻心)"而非"抽象对错"作判准。
    适用:人际决策、文化冲突、道德判断。
  tags: [decision, relativism, 羞耻意识, 人际关系判准]

- id: f09
  title: 树形(直列)vs 网形(并列)组织模型
  type: framework
  source_chapter: 并·平面的组织 (印刷页 41–46)
  source_quote: |
    拥有直列型特征的人员组织架构被称为树形结构。拥有并列型特征的组织架构被称为网形结构。
    树形结构一般适用于较大的组织(效率高);网形结构更适合需要创意的组织(个性充分发挥)。
  summary: |
    选择组织结构时的决策框架:目标明确、需效率→树形(命令链);目标模糊、需创新→网形(并列、自主判断)。
    方法:先问"目标是明确还是混沌",再选结构。适用:企业架构、项目组、任何"该怎么组织"的问题。
  tags: [decision, organization, tree-vs-net, 结构选择]
